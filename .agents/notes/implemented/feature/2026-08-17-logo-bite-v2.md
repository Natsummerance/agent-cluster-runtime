# DoAI LOGO bite-v2 资产迁移

- 日期：2026-08-17
- 类：feature
- 状态：implemented

## 问题

DoAI Workbench 当前品牌资产仍使用对话中较早的 bite-v0 几何：咬痕下接点偏高，A 为尖角三角形，导致 O 的底部不够饱满，也没有落实最新设计反馈中的全圆角处理。

## 决策

- 将参数化源统一升级为 bite-v2：`BITE_R=135`，左侧下接点移动到 `(340.8,570)`，保持 A·I 原比例与右上位置。
- A 使用与 PNG 同源的二次 Bézier 圆角路径，I 使用 `rx=15`；环线改用折线加采样圆帽，避免 Pillow 超采样接缝毛刺。
- 通过 `scripts/gen_logo_assets.py` 一次性重生成前端透明 SVG、README SVG、横排字标、桌面 PNG、Windows ICO 与 icon-source SVG；版本号保持 `0.7.2` 不变。

## 验证

- `uv run --with pillow python scripts/gen_logo_assets.py` 成功生成全部 6 类资产。
- 人工预览 `desktop/build/icon.png`：弧线无毛刺、底部圆滑、A/I 比例稳定、圆角一致。
