# 阵列和声 · Array Harmony

> AgentClusterWorkbench 应用图标设计哲学 —— 设计运动宣言（Phase 1 · Design Philosophy）
> 产物：`icon.png`（1024×1024 主图标）、`icon.ico`（16–256 多尺寸 Windows 图标）

---

## 运动命名

**阵列和声（Array Harmony）** —— 一座由众多独立 agent 组成的编队，在统一节拍下共鸣。它不是"一堆点的堆积"，而是"一次被精密指挥的集体发声"：每个节点既是个体，又是和弦的一部分。

## 哲学宣言

**空间与形体。** 本运动的核心意象是"编队"而非"网络"。网络是静态的接线图，编队是动态的秩序。主体采用经典的七节点布局——一枚中心指挥核，六枚卫星 agent 环绕其周，形成六重对称的晶格阵。中心即"编排者"（orchestrator），卫星即"执行者"（workers），连线不是随意的蜘蛛网，而是经过校准的、等间距的协作通道。空间在此成为语义：越靠近中心，越是决策；越靠近边缘，越是执行。负空间被刻意保留为呼吸的留白，让阵形从深色画布中"浮起"，如同深夜雷达屏上的一次精确回波。

**色彩与材质。** 配色被严格压缩为三束光：深空蓝（画布的寂静）、电光青（协作能量）、紫罗兰（个体角色），并以一点暖琥珀作为指挥核的脉冲。深空蓝不是黑色——它是带着微弱蓝相、可以继续下潜的宇宙底色；青色只出现在能量流通的路径与核心光环上，绝不铺满；紫色赋予每个 agent 以可区分的性格；琥珀仅在中心处一闪，标记"此处有意志"。材质追求"玻璃与等离子"的对比：节点是半透明的玻璃透镜，光线是柔和的等离子晕，两者相遇处有克制的辉光，但绝不使用廉价的外发光滤镜式光污染。

**尺度与节奏。** 比例遵循可感知的数理：中心核与卫星的直径比为 1 : 0.55，轨道半径为核直径的 2.5 倍，连线宽度在 1024 画布上保持约 46px——这是为了让图标缩小到 16px 时，每一条线仍是一根清晰可读的"光束"，而非一抹灰雾。节奏由三重结构控制：外圈淡淡的点阵晶格提供底噪，中圈的环状连线构成主旋律，中心的同心光环构成重音。三个层次各守其位，互不侵占，像总谱上被仔细标注的三条声部。

**构成与平衡。** 画面是严格的中心对称，但通过色彩分布打破机械感：六颗卫星按"青—紫—青—紫—青—紫"交替着色，形成可循环的节律；中心琥珀与外围青紫构成互补的对峙。所有元素被约束在以画布中心为圆心的安全区内（主体边界落在 80% 安全圈以内），背景则满铺至边缘，保证 Windows 任务栏、开始菜单、桌面任意裁剪情境下都不会切断主体。没有文字是刻意的选择：在 16px 的尺度上，任何文字都是噪音；阵形本身即是签名。

**视觉层级。** 视线被引导走一条"先认形、后读色、再观微"的路径：第一眼是整体的星芒轮廓（识别），第二眼是青紫交替的节律（性格），第三眼是中心琥珀的同心脉冲（细节）。三层信息由粗到细，由大到小，由外到内，确保在任何尺寸下，最少的信息依然成立。这是一枚为"被缩小"而设计的图标：它在 256px 上是建筑，在 32px 上是符号，在 16px 上是一个仍然可以被分辨的"星"。

**工艺的执念。** 这件作品必须看起来像一位大师级匠人花费无数小时打磨的产物：每一条弧线都要经过圆心校准，每一道辉光都要经过透明度分级，连背景点阵的疏密都要遵循 64px 的整数网格，而不是随手撒下的噪点。painstaking attention 体现在看不见的地方——对齐误差被控制在 0.5px 以内，圆角与线帽统一为完全相同的值，色阶在暗部做了人眼 gamma 补偿。观众不会知道这些校准的存在，但每一个人都会感受到"这枚图标被认真对待过"。master-level execution 的标准是：当它出现在 4K 桌面上时，边缘如刀切；当它缩到 16px 时，依然有骨相。它是一件可以被挂进博物馆的工业艺术品——不是装饰，而是对"多智能体协同"这一抽象概念的、最精确的视觉证明。

## 配色规范

| 角色 | 色名 | Hex | 用法 |
| --- | --- | --- | --- |
| 画布底色（外） | 深渊蓝 | `#0A101F` | 背景径向渐变外缘 |
| 画布底色（心） | 星夜蓝 | `#16233E` | 背景径向渐变中心微光 |
| 能量主色 | 电光青 | `#35D6F4` | 协作连线、核心光环、半数卫星 |
| 角色次色 | 紫罗兰 | `#8B7CF6` | 半数卫星、次要环线 |
| 意志脉冲 | 琥珀 | `#FFC24B` | 指挥核内芯 |
| 底噪点阵 | 星尘白 | `rgba(203,213,225,0.13)` | 背景晶格点 |
| 辉光 | 柔光青 | `rgba(53,214,244,0.35)` | 核心外圈光晕、卫星微光 |

规则：画布永远保持深色满铺（图标不依赖透明角来"伪装圆角"）；青色总量 ≤ 画面 8%；琥珀仅出现一次；所有辉光必须由同心渐变叠加实现，禁止滤镜式外发光。

## 构图规范

- 画布：1024×1024，方形满铺。
- 主体：七节点编队（1 指挥核 + 6 卫星，正六边形轨道），外接圆直径 ≈ 660px，完全落在中央 80% 安全区（102–922px）内。
- 连线：从中心到 6 卫星的径向梁，线宽 ≈ 46px，圆头线帽；相邻卫星之间以细弧（约 20px）连接，暗示"互通"而非"星形依赖"。
- 同心结构：核心 = 琥珀内芯 + 青色外环 + 柔光晕；卫星 = 玻璃透镜圆点 + 半透明白高光。
- 底噪：以 64px 间距的整数点阵铺满全画布，最外两圈略微淡出，制造深度。

## 可伸缩性规范

- 16px 可辨识判据：整体呈"中心亮核 + 六向射线"的星芒剪影，无需看清节点细节。
- 最小笔画宽度 ≥ 画布的 4.5%（46px @1024 → ≈0.7px @16px）。
- 禁止：细于 2px（@1024）的装饰线、依赖文字传达身份、透明背景上悬空的元素。
