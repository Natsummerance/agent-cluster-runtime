# Postmortem（v0.7 T14.8，dsh docs/postmortem 契约移植）

## 定义
Postmortem 只写给「bug 到达了不该到的地方」：真实用户、合并 PR 或发布。
重点写**为什么流程放过了它**，而不是复述现象。

## 三条件（全部满足才写）
1. **隐蔽**：单测/门禁无法轻易发现；
2. **系统性**：不是一次性失误，流程层面有缺口；
3. **重新发现代价高**：下次再现的成本远高于本次修复。

## 模板（每篇以 Executive summary 开头）
```markdown
# 00XX-短横线主题.md

## Executive summary
（2-3 句：现象、为什么流程放过它、修复动作）

## 时间线
## 根因
## 为什么门禁没拦住（关键！）
## 修复
## 防复发措施
```
