## 4. 执行模式（新对话必须继承，这是用户明确要求）

1. **每个小步骤都交给子智能体执行**：主线程少做事、只做合成与决策（用户原话：上下文太长导致能力下降，每个小步骤交给子智能体即可）。spawn 子智能体**不指定 model 参数**（本环境只支持 deepseek-v4-pro/flash，传 gpt-5.6-luna 会报错）；`send_input` 用 items（text 项需带 `name`），不要同时传 message 字符串。
2. **superpowers 流程**：先 `superpowers:writing-plans` 出计划落 `docs/superpowers/plans/`，再 `superpowers:executing-plans` / `superpowers:subagent-driven-development` / `superpowers:dispatching-parallel-agents` 执行，完成前 `superpowers:verification-before-completion`。
3. **每 Task 门槛**：后端全量 `uv run pytest -q` 全绿 → commit（**英文 message，前缀 `Task xx.y`**）→ push。前端改动跑 `tsc --noEmit` / `npm run build` / Vitest / Playwright。
4. **push 必须用内联 token**（其他方式会挂起）：
   `$env:GIT_TERMINAL_PROMPT='0'; git -C <repo> -c credential.helper= push "https://x-access-token:$($env:GITHUB_TOKEN)@github.com/Natsummerance/agent-cluster-runtime.git" main`
5. **apply_patch 不可用**：写新文件用 PowerShell here-string + `[System.IO.File]::WriteAllText($p, $c, [System.Text.UTF8Encoding]::new($false))`（UTF-8 无 BOM）；改已有文件用 Python：`io.open(p,"r",encoding="utf-8").read()` → `str.replace` → `io.open(p,"w",encoding="utf-8",newline="").write(...)`（保持 LF）。
6. **语言**：与用户中文交流；commit/release 文案英文。
7. **模型**：默认当前对话模型 `deepseek-v4-flash`（`--model codex` 解析 Codex 配置，cc-switch 映射）；`--deterministic` 用于演示/测试（无 key）。
8. **技能**：前端/桌面任务指派给子代理时显式附带 `frontend-design`、`team-skills-platform:frontend-engineering`、`team-skills-platform:frontend-ui-ux-system`；代码评审用 `code-review`；测试开发用 `superpowers:test-driven-development`；调试用 `superpowers:systematic-debugging`。
9. **规划按 token 不按时间**：迭代容量 = token 预算，任务带 token 预估，角色/阶段/产物全量 token 计量，预算超限升级人工。

## 6. 关键契约（勿破坏）

- `SessionDriver(workspace, goal, flow, model, budget, rework_limit, yes, deterministic, resume, qa_script, tool_script, role_tool_scripts, skills_root, mcp_servers, mcp_http_servers, max_rounds, prompt_fn, print_fn, event_printer, phase_map, plugin_manager, sandbox, judge)`；`run()` 返回 `BuildResult`；测试必须注入 `prompt_fn`（如 `lambda hint: "/skip"`）。
- `WorkbenchServer(host, port, auth_token, plugins_dir, mcp_servers, mcp_http_servers)`；端点响应统一 `{"ok":true,"data":{...}}`；SSE `GET /sessions/{sid}/events?since=N`；认证头 `X-Auth-Token`；默认 `http://127.0.0.1:8765`。
- `ChatResponse(text, tool_calls, usage)`；`TokenUsage{prompt/completion/total_tokens, model}`；三协议归一化（chat/responses/anthropic）。
- 工具权限：`read` 自动、`workspace_write` 自动+审计、`dangerous` 走门（`--yes` 自动拒绝）；`human_interaction` 权限 + `ask_user` 工具（PM/docs）。
- 记忆：SQLite 四级晋升（session→project→gotcha→domain）+ Markdown 内容文件（可 git 追踪回滚）+ 提议制写入。

## 7. 已确认决策（54 项征询结论，v0.5 定稿）

组合式架构：LangGraph 流程/审批门底座 + CrewAI/MetaGPT 角色体系 + anthropic-skills 技能规范 + ChatDev 图编排 + AutoGen 群聊。核心取舍：少即是多（简单循环+强模型+错误恢复）、HITL 建立在持久 checkpoint（FileCheckpointer）、记忆分级晋升、token 调用前决策（预算/路由/缓存）。桌面形态：Electron 壳内嵌后端、React+Vite、SSE+HTTP、面板+终端双入口、实时打断可回滚、并行多会话、四级记忆、LLM-as-judge、四类健康仪表盘、NSIS 安装包+CLI 并存、纯本机、GitHub Releases、远程 MCP（Streamable HTTP）、进化提案自动生成。
