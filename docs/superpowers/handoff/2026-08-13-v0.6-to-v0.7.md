- 每任务独立 commit + push，提交前缀 `Task 14.N:`（v0.6 为 `Task 13.N:`）；push 使用内联 `GITHUB_TOKEN`。
- 前端严禁伪造/硬编码数据，全面接真实后端；`frontend/e2e/mock-api.ts` 仅 Playwright 拦截式测试用。
- 流程 TDD（RED→GREEN）+ `verification-before-completion`——完成声明必须附当次运行的新鲜证据输出。
- `apply_patch` 报 `Access is denied`（Z: 盘/权限）=> 用 PowerShell `[System.IO.File]::WriteAllText`（UTF-8 无 BOM）或 `uv run python -` 写文件。
- 单条 shell 命令过长会被策略拦截 => 长内容拆多条命令；组合命令（`Remove-Item` 等）也拆开，必要时用 .NET API。
- 不派发子智能体（用户明确要求）；主线程直改。
- CRLF 警告是 git autocrlf 行为，无害。
