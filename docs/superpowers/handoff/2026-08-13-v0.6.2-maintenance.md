## 5. 关键契约（写代码/测试前必看）

- **API 信封**：响应 `{ok, data}`；`data` 常为对象（`proposals`/`plugins`/`skills`/`mcp`/budget/三轴 dashboard）。
  前端端点函数必须解包后返回数组/结构；测试 mock 用真实信封（`{ok:true,data:{proposals:[...]}}`），
  用 `data: []` 会掩盖契约不匹配（antd Table 收到对象即崩：`rawData.some is not a function`）。
- **CORS**：`server.py` 已全局 `ACAO: *` + `do_OPTIONS`（允许 `X-Auth-Token`/`Content-Type`）+ SSE 也带 ACAO。
  浏览器 dev（5173）与桌面（file://）直连 8765 均可用。
- **旧项目语义**（v0.6 T13.5 双写前：全局索引有、ProjectStore 无）：
  `dashboard`→空三轴 200；`tasks`→空列表 200；`budget`→默认预算结构 200；`workspace/memory/evolution`→走索引正常。
  完全不存在 → 404 `not_found`。新增项目级端点遵循同样兜底。
- **workspace 解析**：`project_workspace()` 优先全局索引 entry 的 workspace 字段。
- **版本断言**：`_package_version()` 开发回退 `0.6.2-dev`；版本同步 12 处清单见 `docs/lessons/06-versioning.md`。
- **i18n**：key `<page>.<component>.<token>`；`errors.*` snake_case 对齐后端 code；测试用 `renderWithIntl`；
  AntD 下拉无 role=option → `.ant-select-item-option` + hasText。
- **测试**：`tests/test_t12_11.py` 的 `workbench` fixture（in-process serve）是后端端点测试标准写法；
  `ws.index.add_project(id,name,workspace)` 可构造"仅索引"旧项目场景。

## 6. 执行模式与约束（延续）

- 每任务独立 `git commit` + `git push`；前缀 `Task 13.18:`（v0.6.x 维护）/ `Task 14.N:`（v0.7）。
- 前端**严禁伪造/硬编码数据**，全面接真实后端；`frontend/e2e/mock-api.ts` 仅拦截式测试合法。
- 流程 TDD（RED→GREEN）+ verification-before-completion（完成声明附当次新鲜证据）。
- `apply_patch` 报 Access denied → `[System.IO.File]::WriteAllText`（UTF-8 无 BOM）。
- 单条命令过长/`Remove-Item` 被策略拦 → 拆多条 + .NET API；CRLF 警告无害。
- **不派发子智能体**（主线程直改）。
- **3 次即停**：同一问题修复 ≤3 次，第 3 次仍失败 → 停止 → `scripts/troubleshoot.ps1` 取证 → 对照经验库 → 书面根因才可再修。
