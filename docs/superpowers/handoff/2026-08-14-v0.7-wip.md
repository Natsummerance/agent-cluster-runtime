## 1. 后端架构速查

- 入口：`src/agent_cluster/cli.py`（argparse 子命令）→ `server.py:serve_main/build_server` → `WorkbenchHandler`。
- HTTP 服务：`src/agent_cluster/server.py`，纯 stdlib `ThreadingHTTPServer`。
  - 响应信封：`{"ok": true, "data": ...}`；错误 `{"ok": false, "error": msg, "code": code?}`（`_send_error`，code 在顶层）。
  - 路由分发在 `WorkbenchHandler.do_GET/do_POST/do_PATCH/do_DELETE`：`parts = self._path_parts()` 后按 `parts[:3] == ["api","v1",xxx]` 匹配；404 兜底；`KeyError→404`、`PermissionDenied→403 code=permission_denied`、其余→500。
  - handler 方法命名 `_handle_xxx`，放 `# handlers` 段；服务对象经 `self.server.workbench` 访问。
  - 认证：`_check_auth()`（Bearer 或 X-Auth-Token）；`_auth_user()` 返回当前用户（默认 admin）；`_require_permission(perm, project_id=None)` 走 RBAC。
- 模型：`src/agent_cluster/models.py`（pydantic BaseModel + StrEnum）。
- 接缝：`src/agent_cluster/seam.py`（`SeamRegistry`，`register(name, provider) -> Registration`，重复注册抛 `DuplicateProviderError`，`effect_scope` 逆序回滚）。
- 事件日志：`src/agent_cluster/events.py`（`SessionEvent`、`KNOWN_SESSION_EVENT_TYPES`、`derive_messages`、`verify_derivation`）。
- RBAC：`src/agent_cluster/rbac.py`（`PERMISSION_MATRIX` 12 岗→权限、`RbacStore`、`AuthzProvider` 注册为 seam `"authz"`）。
- 认证：`src/agent_cluster/auth.py`（`LocalAuthProvider`/`LdapAuthProvider`/`OidcAuthProvider`、`TokenService` HS256 access/refresh）。
- 配置分层：`src/agent_cluster/config_layers.py`（profile/bundle/patch，`dump_config`、`assert_activated`）。
- 会话/项目：`src/agent_cluster/session_manager.py`（`SessionManager`/`ProjectStore`）、`projects.py`（`fork_session`、`BudgetPoolExhaustedError`、`GatePolicyConfig`、`ProjectStore`）、`trace.py`（`build_audit_package`、`compute_health`、`Tracer`）、`worktree.py`、`memory.py`、`evolution_integration.py`。
- 测试：`tests/` 平铺，命名 `test_t14_N.py`（v0.7 新增）。服务端测试模式见 `tests/test_t14_9.py`（`_make_server` fixture：monkeypatch `server_mod.INDEX_DIR`、`ThreadingHTTPServer(("127.0.0.1",0), WorkbenchHandler)`、`httpd.workbench = workbench`、`_request(port, method, path, body, headers)`）。
- **dsh 契约出处**：`docs/porting/2026-08-14-dsh-porting.md`（搬运/不搬运清单，MIT）。dsh 源码克隆在 `T:\Programming\Project\codex\agent\deepseek-harness`（基线 `47f943859b`），**可读、可参考，禁止改动**。
