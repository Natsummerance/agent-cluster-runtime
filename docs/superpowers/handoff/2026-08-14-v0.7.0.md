## 5. 后端模块索引（50 模块，按层分组，一句话）

**入口与 HTTP**
- `cli.py` — CLI 入口：run/build/demo/chat/serve/dump-config/stdin/doctor/tools/list/mcp/plugins/skills/roles/proposals/metrics/eval/evolution 子命令。
- `server.py` — serve 后端：stdlib ThreadingHTTPServer + SSE + WS 升级 + 全局索引 + 响应信封 + 认证/RBAC 拦截（最大单文件，路由见 §7）。
- `repl.py` — `agent-cluster chat` 连续多轮 REPL 入口。
- `eval.py` — 确定性场景回归（mini-pm-gate/dev-qa-gate/full-build）+ 基线对比防退化。
- `doctor.py` — `agent-cluster doctor` 预检：环境/配置/工具链（含 Node/MCP HTTP 检查）。

**模型与领域层（v0.5 前既有）**
- `models.py` — pydantic 数据模型：消息/状态/会话/项目核心模型。
- `session.py` — 会话层：FileCheckpointer + TokenLedger + SessionStore + SessionDriver。
- `session_manager.py` — 项目级并发/预算/事件编排 + worktree 默认隔离 + merge_back。
- `projects.py` — 项目数据模型 + ProjectStore 权威存储（v0.5→v0.6 目录迁移）。
- `tokens.py` — 统一 token 估算与用量计算（独立模块避免循环导入）。
- `pricing.py` — token 价格表与金额折算（自适应预算按 token 不按时间）。
- `budget.py` — 项目预算池：预警滞回/硬上限/解锁审批/聚合归因。
- `ledger.py` — 账本与任务板（LedgerStore + TaskBoard，Magentic-One 心智）。
- `gates.py` — 审批门（HITL interrupt）：条件路由/置信度升级/bypass-immune 无人值守。
- `changes.py` — 需求变更版本化：实时打断 + 变更历史 + 回滚。
- `roles.py` — 组织角色：12 岗位目录 + RoleKind 映射 + RoleRegistry。
- `memory.py` — 经验库：SQLite 四级晋升 + 提议制写入 + 检索。
- `evolution.py` — 六步进化闭环（collect→distill→propose→review→apply→rollback）+ 安全治理。
- `evolution_integration.py` — 记忆失败模式→自动提案→复盘报告→纪要提炼/SOP。
- `meetings.py` — MeetingHost 生成 7 类会议纪要 + meeting 节点 handler。
- `metrics.py` — 绩效度量：MetricsCollector + 阈值规则引擎（v0.7 扩展缓存命中率信号）。
- `judge.py` — LLM-as-judge 质量门禁 + eval 回归集集成。

**事件溯源（v0.7 地基 A）**
- `events.py` — 会话事件日志核心：SessionEvent（type/seq/ts/payload）、34 类型词汇、derive_messages、verify_derivation（model-visible ⟺ logged 不变量）。
- `session_log_store.py` — JSONL + SQLite WAL 双后端持久化：SESSION_FORMAT_VERSION=1、revision 令牌、方向感知拒绝、ignorable 跳过、v0.6 自动迁移。
- `spill.py` — 大输出溢出契约：maxInlineBytes=50000 溢出到 0700 磁盘 + head/tail 预览。

**接缝与能力（v0.7 地基 B）**
- `seam.py` — 能力接缝运行时：SeamRegistry + register(name, provider)→Registration + effect_scope 逆序回滚 + 重复 provider fail-loud，纯 stdlib。
- `credentials.py` — 凭据契约：只存环境变量名引用、每操作解析、空=不存在、env+file 分层。
- `guard.py` — 工具 guard：合作式超时 TOOL_TIMEOUT + 重复调用提醒。
- `cache.py` — LLM 上下文缓存统计（usage 回填 cache_read/cache_miss_tokens + 命中率指标）。
- `context.py` — 头锚定上下文管理：保头+定价尾部、中间剪枝、不拆 tool-call/result 对（dsh compaction-basic 移植）。
- `providers.py` — 模型供应商配置解析：读 Codex 配置复用当前对话模型（codex/deterministic/deepseek-*）。
- `runtime.py` — 角色执行层：ChatModelClient + AgentRuntime + EventBus + agent 节点 handler（ctx.llm 接缝接线）。

**认证与治理（v0.7）**
- `auth.py` — 认证层：AuthProvider 抽象 + Local/Ldap/Oidc 三 provider + TokenService（HS256 access+refresh）。
- `rbac.py` — RBAC：12 岗→权限矩阵 PERMISSION_MATRIX + RbacStore + AuthzProvider 注册为 seam `authz`。
- `tenancy.py` — 多租户：Tenant/TenantStore CRUD + 配额 + 命名空间存储 + per-tenant 配置分层。
- `config_layers.py` — 配置分层：profile/bundle/patch，YAML 按 id 整块替换+disabled、`--dump-config`、assertEntriesActivated fail-loud。

**v0.7 史诗模块**
- `oauth_mcp.py` — OAuth MCP 授权服务器（RFC 8844/6749/7636）：/.well-known 两元数据 + /authorize + /token（PKCE S256，纯 stdlib）。
- `orchestration.py` — 高级编排：plan/goal/jobs/schedule（dsh 语义：plan/mode 折叠、goal CAS+轮次上限、jobs first-wins settlement、schedule 五分钟下限）。
- `calendar.py` — 资源日历：Availability/ResourceCalendar CRUD + 重叠冲突 fail-loud（岗位×时间段）。
- `dependency_graph.py` — 跨项目依赖图：依赖边 + 环检测 + 影响分析 + 依赖感知调度。
- `trace.py` — 可观测性：span 追踪 + 审计导出（CSV/JSON/Markdown + sha256 哈希链 prev_hash + retention_days）+ 健康指标。

**工具与执行层（v0.2-v0.4 既有）**
- `tools.py` — 工具注册表 + 受限工作区执行会话（权限分层/路径越界/多 hunk/白名单）。
- `subagent.py` — 有界子代理：ReAct 循环 + token/轮数截断（参考 openhands/swe-agent）。
- `worktree.py` — git worktree 隔离管理器（按角色隔离 + merge_back）。
- `sandbox.py` — Docker 沙箱执行器（`--sandbox docker`）。
- `mcp_client.py` — MCP 轻量 stdio 客户端：JSON-RPC 2.0 逐行协议，零新依赖（v0.7 扩展 OAuth 远程流）。
- `plugins.py` — 插件层：双规范插件清单 + marketplace + hooks（11 hooks，v0.7 兼容适配到 seam 事件）。
- `skills.py` — 技能层：SKILL.md 加载/注册/渐进披露。
- `workflow.py` — 流程引擎：YAML DSL→LangGraph StateGraph 编译（v0.7 扩展资源约束/依赖边）。
- `ws.py` — 自研最小 RFC 6455 WebSocket（仅 stdlib，无第三方）。
- `cache.py`/`context.py` 见上（接缝组）。

**数据流速读（一次会话怎么跑）**
`cli serve` → `WorkbenchHandler`（认证→RBAC→路由）→ `SessionManager` 起会话 → `SessionDriver` 驱动 `AgentRuntime`（ctx.llm 接缝调模型）→ 每步写 `events.py` 事件日志（JSONL/SQLite）→ 审批走 `gates`/预算走 `budget`/账本走 `ledger` → SSE/WS 推前端；恢复=从事件日志重放（检查点仅派生缓存）。

## 7. API 端点索引（方法 → 路径 → handler）

## 15. 关键契约索引（不可违反，写代码前必读）

1. **响应信封**：`{"ok":true,"data":...}` / `{"ok":false,"error":...,"code":...}`（code 在顶层）；`KeyError→404`、`PermissionDenied→403`、其余→500。
2. **认证**：X-Auth-Token 或 Authorization: Bearer；`_check_auth`/`_auth_user`/`_require_permission(perm, project_id)`；认证启用后才允许 `--host 0.0.0.0`。
3. **事件日志不变量**：model-visible ⟺ logged（§8）；JSONL 头行 `{"type":"session","version":1,"id","createdAt","cwd","parentSession","seedLength"}`，SESSION_FORMAT_VERSION=1；写者决定 bump、方向感知拒绝、ignorable 跳过。
4. **接缝（seam.py）**：registrations are effects——一切注册都是 effect，作用域退出逆序回滚；重复 provider fail-loud；explicit > implicit（`resolve(request)->spec`）。
5. **凭据（credentials.py）**：只存环境变量名引用、每操作解析、空=不存在、env+file 分层；guard：TOOL_TIMEOUT 合作式超时 + 重复调用提醒。
6. **LLM 缓存**：usage 必回填 cache_read/cache_miss；DeepSeek 专属头 `x-deepseek-harness-session-id`+`x-deepseek-harness-compact: 1`（**无匿名 user-id**）；observe 保头+定价尾部、不拆 tool 对；命中率=hit/(hit+miss) 稳态≥98%（发布门槛）。
7. **配置分层**：按 id 整块替换+disabled；`--dump-config` 离线渲染；启动 assertEntriesActivated fail-loud。
8. **编排（orchestration.py）**：plan/mode 折叠；goal/change CAS+轮次上限；jobs first-wins settlement+owner 授权；schedule at/after/every 五分钟下限。
9. **迁移**：v0.6 `session.json` → `migration/restored` 幂等自动迁移；用户数据不丢；REST 契约不变 → 桌面 electron-updater 平滑升级。
10. **RBAC**：12 岗权限矩阵 + per-project 作用域；新管理端点先补 `PERMISSIONS`/`PERMISSION_MATRIX`。

## 16. 执行模式与约束索引（每时每刻）

- **提交**：每任务独立 commit+push；前缀 `Task 14.N:`（v0.7）/`Task 15.N:`（v0.7.x）；只 `git add` 自己改的文件（勿 `git add -A`）。
- **push 必走代理**（直连 schannel 失败）：
  `git -c http.proxy=http://127.0.0.1:7897 -c https.proxy=http://127.0.0.1:7897 push "https://x-access-token:$env:GITHUB_TOKEN@github.com/Natsummerance/agent-cluster-runtime.git" main`
- **文本编辑**：`apply_patch` 不可用（Access denied）→ `uv run python -` heredoc（`Path.write_text` 精确替换）或 `[System.IO.File]::WriteAllText`（UTF-8 无 BOM）。
- **heredoc 陷阱**：PowerShell 包装器会拦含 ""/反引号/$ 的长 heredoc——用占位符（反引号用占位符表示）在 Python 内 chr(96) 还原（本文档即此法生成）；单引号内嵌 " 曾损坏文件。
- **3 次即停**：同一问题修复尝试 ≤3；第 3 次失败 → `scripts/troubleshoot.ps1` 取证 → 对照 lessons/ → 书面根因后才可再修（07 协议）。
- **TDD + 新鲜证据**：完成声明附当次测试输出/探活输出；前端严禁伪造数据。
- **子智能体**：默认不派发（AGENTS.md 硬约束）；用户显式授权时可派（v0.7 的 14.11–14.17 即如此），派发必须写 WIP 索引交接。
- **生成物 freshness**：改配置/模块后必须重跑 gen_*（§11），否则 CI/test_t14_8 挂。
- **勿改**：WIP handoff `2026-08-14-v0.7-wip.md`、移植清单 `docs/porting/2026-08-14-dsh-porting.md`（只读参考）；dsh 源码目录只读。
