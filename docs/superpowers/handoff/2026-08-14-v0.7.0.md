## 5. 关键契约（写代码/测试前必看）

- `model-visible ⟺ logged`：模型请求必须能从事件日志重建（`verify_derivation`），违反抛 InvariantViolationError；FileCheckpointer 降为派生缓存，恢复=重放。
- JSONL 头行：`{"type":"session","version":1,"id","createdAt","cwd","parentSession","seedLength"}`，SESSION_FORMAT_VERSION=1；写者决定 bump、方向感知拒绝、ignorable 跳过；v0.6 `session.json` 自动迁移为 `migration/restored`（幂等）。
- LLM 缓存：`TokenUsage.cache_read_tokens`+`cache_miss_tokens`；DeepSeek 头 `x-deepseek-harness-session-id` + `x-deepseek-harness-compact: 1`（`无匿名 user-id 头`）；observe 截断=保头+定价尾部、不拆 tool-call/result 对；命中率=hit/(hit+miss) 稳态≥98%。
- 配置分层：YAML 按 id 整块替换+disabled、`--dump-config` 离线渲染、启动 assertEntriesActivated fail-loud；profile：serve/chat/headless。
- 认证：启用认证后才放开 `--host 0.0.0.0`（默认 127.0.0.1）；token 注入 `Authorization: Bearer` 或 `X-Auth-Token`。
- 编排：plan/mode 折叠、goal/change CAS+轮次上限、jobs first-wins settlement+owner 授权、schedule at/after/every 五分钟下限。
- 前端路由：`/login` 外全部在 RequireAuth+AppLayout 内；`/users /teams /tenants /calendar /dependencies /plans` 为 v0.7 新增。
- 版本：pyproject/__init__/前端+桌面 package.json = 0.7.0；server dev 回退 `0.7.0-dev`。
