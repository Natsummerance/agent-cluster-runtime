## 2. v0.8.0 核心发布特性与重大修复

1. **Git Worktree Manager 继承语义修复 (`src/agent_cluster/worktree.py`)**:
   - 修复了 `WorktreeManager.ensure_repo()` 在首次仓库初始化时未执行 `git add -A` 导致新建 worktree 分支脱离主工作区文件的问题。
   - 彻底解决了会话分支继承与 fork 时 PRD/文档丢失缺陷，全量 `test_fork.py` 用例 100% 绿灯。
2. **前端 API Client 默认 BaseURL 解析鲁棒性增强 (`frontend/src/api/client.ts`)**:
   - 移除 `window.location.origin` 劫持对 Vitest / JSDOM 测试环境的干扰。
   - 严格按照优先级解析：`Electron 注入 > URL ?backend= 参数 > 默认单机端口 http://127.0.0.1:8765`。
3. **极速开发（Quick Run）一键体验闭环**:
   - 首页默认加载 Quick Run 面板，支持零门槛直接输入需求、启动多 Agent 会话，前后端链路 100% 闭环打通。
4. **全量版本号同步（12 处契约清单）**:
