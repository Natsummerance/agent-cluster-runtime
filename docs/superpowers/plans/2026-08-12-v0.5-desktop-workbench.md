# v0.5.0 桌面工作台（Desktop Workbench）实施计划

> 日期：2026-08-12 ｜ 状态：approved（54 项需求征询 + 3 份 deep-research 调研后定稿）

## Goal
把 `agent-cluster-runtime` 从 CLI 工具升级为单机桌面应用：Electron 壳内嵌后端，
一个需求 → 面板全程交互（实时打断改需求、门审批、看板、token/成本仪表盘）→ 产出完整产品。
CLI 完全保留，后端 451 测试全绿为硬基线。

## Architecture
- 后端：stdlib ThreadingHTTPServer + SSE + asyncio 单进程多会话（serve 子命令）
- 桌面：Electron + electron-builder（NSIS），内嵌启动 `agent-cluster serve`
- 前端：React 18 + Vite + TypeScript + Ant Design 5 + React Router + zustand
- 记忆：SQLite 四级晋升（session→project→gotcha→domain）+ Markdown 内容文件
- 交互：SessionDriver.inject_change 实时打断 + 变更版本树可回滚 + 阶段依赖重规划
- 可观测：自研 trace span + 四类健康指标 + 审计导出（Markdown/JSON）+ exporter 预留
- 质量：LLM-as-judge 门禁 + eval 回归集（任务完成率/工具正确性/测试通过率）
- Token：自适应预算（历史 estimate_accuracy 校准）+ 内置价格表折算金额 + 前缀缓存

## Tech Stack
Python 3.11（保持）、pydantic v2、langgraph（现有）；Node 22 + npm（前端/桌面）；
零新后端重量依赖（stdlib HTTP/asyncio/sqlite3）。

## Global Constraints
- 后端测试全绿为每 Task 硬门槛；per-task commit（英文 message）+ push
- 不传 --serve/新参数时既有行为不变；Windows 优先，其余平台兼容不验收
- 纯本机运行；API 默认 127.0.0.1 + 可选 --auth-token
- apply_patch 不可用（Access denied）→ 用 Python 脚本写文件并保持 CRLF
